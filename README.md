# 🎓 Taaleemi Markaz

A modern, responsive **Urdu educational and tutoring center website** designed with a focus on RTL layouts, accessibility, and a clean modern interface.

## 🌐 Live Demo

**[View Taaleemi Markaz](https://mhishaambinsaghir-tech.github.io/Taaleemi-Markaz/)**

## ✨ Features

* 🇵🇰 Urdu-focused **RTL (Right-to-Left)** design
* 📱 Fully responsive layout
* 📚 Course showcase
* 👨‍🏫 Teacher profiles
* ⭐ Student testimonials
* 🖼️ Educational gallery
* 📝 Registration/contact form
* ✨ Smooth scrolling and scroll animations
* 📱 Mobile-friendly navigation
* 🎨 Modern educational UI

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **Vanilla JavaScript**
* **Google Fonts**
* **Font Awesome**

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/mhishaambinsaghir-tech/Taaleemi-Markaz.git
cd Taaleemi-Markaz
```

Then open `index.html` in your browser.

No dependencies or build tools are required.
